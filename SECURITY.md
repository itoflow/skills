# Security

Report a vulnerability privately through
[GitHub's private reporting](https://github.com/itoflow/skills/security/advisories/new),
or email support@itoflow.ai with "Security" in the subject. Do not open a public
issue. Include the affected file or plugin version and the steps to reproduce.

This repository holds instructions and configuration only. The plugins
connect to `https://mcp.itoflow.ai/mcp`, and your client handles sign-in.
No file here should contain a token, key or password. If you find one, report
it as above.

Report problems with the Itoflow service itself the same way.
